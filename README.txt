DESIGN WORKFLOW KIT v1.0
========================
Plan, track and document any design project in one file.
Works offline. No account, no install, no data leaves your device.

QUICK START
1. Open Design_Workflow_Kit.html in Chrome, Safari, Edge or Firefox
   (phone or desktop).
2. Pick a template at the top, then tap "New from template":
   - Product page image (AI + composite)
   - Apparel / headwear tech pack
   - Brand identity kit
   - Blank project
3. Work through the steps. Every step has asset slots with a fixed
   aspect ratio. Tap a slot to add an image.
4. For stock photos, fill in source URL, photographer and licence.
   The tool warns you when one is missing.
5. Tick the QC checklist. The progress bar tracks it.
6. Export document = clean printable page (save as PDF).
   Export JSON = backup of the whole project, images included.
   Import JSON = restore it later or move it to another device.

GOOD TO KNOW
- Your work is saved in your browser. Clearing browser data erases it,
  so use Export JSON regularly.
- Browser storage holds about 5 MB. Many large images can fill it;
  the tool shows a warning. Export JSON when you see it.
- THEME button cycles Auto / Day / Night.
- Edit anything: step names, descriptions, slot names, ratios,
  checklist items, prompts.

ADD YOUR OWN TEMPLATE
Open the HTML file in any text editor. Find "const TEMPLATES".
Copy one block, change the key, label, steps and checklist, save.
